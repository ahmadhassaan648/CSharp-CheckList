# C# CheckBoxes Project (Windows Forms) 📚

## 📌 Project Description
This is a simple Visual Programming project developed in C# using Windows Forms.  
It demonstrates the use of **CheckBox control** to allow users to select multiple items like books, movies, and colors.  

When the user clicks the button, all selected items are displayed in a MessageBox.

---

## 🧠 Features
- Items Selection Using ChcekBoxes
- Display selected items in MessageBox
- Simple and beginner-friendly UI
- Event-driven programming concept

---

## 🛠️ Technologies Used
- C#
- Windows Forms (.NET Framework)
- Visual Studio

---

## 📷 How It Works
1. User selects items from the list (Books, Movies, Colors, etc.)
2. Clicks the **Show Button**
3. Program displays selected items in a MessageBox
